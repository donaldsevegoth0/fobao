# Fobao 项目

一个基于 **Vue 3 + Vite + Supabase** 构建的在线应用。

用于快速搭建具备登录、数据存储与展示的 Web 应用，并支持 Vercel 部署。

---

## 技术栈

- Vue 3（Composition API）
- Vite
- TypeScript
- Supabase（Auth + Database + Storage）
- Vue Router
- Vercel（部署）

---

## 功能

- 用户注册 / 登录 / 登出
- Supabase 用户认证
- 数据读取与展示
- 图片/内容上传（如已启用 Storage）
- SPA 路由切换
- 响应式前端页面
